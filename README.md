**Pixel Rush** is a fun and challenging 2D endless traffic-dodging game developed for Android using Kotlin and Jetpack Compose.

Drive through busy traffic, dodge incoming vehicles, beat your high score, and unlock new cars!

---

## 🎮 Version 2.0 — What's New?

Version 2.0 introduces major improvements to gameplay, vehicle visuals, traffic generation, and the overall gaming experience.

### 🚘 Vehicle Improvements
- Added multiple enemy vehicle PNG assets.
- Added 5 selectable player cars.
- Improved enemy vehicle dimensions and visual consistency.
- Fixed stretched player car proportions.
- Improved vehicle rendering and aspect ratio handling.
- Added sequential enemy vehicle selection.

### 🚦 Traffic & Gameplay
- Improved enemy vehicle spawning system.
- Reduced the time interval between incoming vehicles.
- Increased traffic density for a more challenging experience.
- Improved vehicle spacing and lane distribution.
- Added more dynamic traffic patterns.
- Maintained three-lane gameplay.
- Improved collision detection using actual vehicle dimensions.

### 💥 Crash & Effects
- Added pixel-style explosion animation.
- Added crash particle effects.
- Added device vibration feedback when crashing.

### 🏎️ Garage & Unlock System
- Added a vehicle selection garage.
- Introduced 5 player vehicle options.
- Added an unlock progression system.
- Unlock new cars by earning score.
- New vehicles become available every 15 best-score points.
- Saved selected vehicles and progress using SharedPreferences.

### 🎨 UI & Game Experience
- Added a splash screen with a custom game logo.
- Improved the main menu.
- Added an in-game score display.
- Added a best-score tracking system.
- Added a game-over screen.
- Improved overall visual presentation.

---

## 🛠️ Built With

- **Kotlin** — Main programming language.
- **Jetpack Compose** — UI and game rendering.
- **Android Canvas** — Custom game environment and graphics.
- **Android SharedPreferences** — Saving player progress and preferences.
- **Android Vibration API** — Crash feedback.
- **PNG Assets** — Player and enemy vehicle graphics.
